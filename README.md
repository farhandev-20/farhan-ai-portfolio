# Farhan Attar — Conversational AI Portfolio 🚀

An Apple-inspired, minimalist, conversational AI portfolio web application for **Farhan Attar** (Computer Engineering Student, Class of 2027).

![Portfolio Preview](profile.jpg)

## ✨ Highlights & Features

- **🍎 Minimal Apple Aesthetic:** Clean typography, glassmorphism cards, and fluid cursor background.
- **💬 Interactive Chatbot Engine:** Instant answers for *Me*, *Projects*, *Skills*, *Contact*, *Location*, and *Resume*.
- **🎯 Intelligent Focus Navigation:** Automatically focuses on newly opened answers with smooth, offset scrolling.
- **🛰️ Real Earth Satellite View:** Integrated high-resolution satellite imagery (Esri World Imagery) with cinematic fly-in from space down to Barshi, Maharashtra (`18.2329° N, 75.6953° E`).
- **📄 Direct PDF Resume Download:** Instant viewing and downloading of verified official resume (`Farhan_Attar_Resume.pdf`).
- **📱 Ultra-Responsive Mobile Design:** 3×2 grid layout, safe-area inset support, and smooth touch gestures.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern Vanilla CSS3, JavaScript (ES6+)
- **Satellite Map:** Leaflet.js & Esri World Imagery (High-Resolution Tiles)
- **Fluid Visuals:** WebGL2 Fluid Dynamics Simulation
- **Deployment:** Vercel / GitHub Pages

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/farhandev-20/farhan-ai-portfolio.git
   cd farhan-ai-portfolio
   ```

2. Open `index.html` directly in any modern web browser or serve locally:
   ```bash
   npx serve .
   ```
